## ⚠️ 国庆档三条硬约束

1. **门票必买**：135 元/人 ×4 = 540 元。工作日免票政策「法定节假日除外」，你们不适用。
2. **提前 3 天预约**：微信公众号「五台山」实名预约，有每日上限，约满即停。**今天就去约 10/2、10/3 两天**（门票当日当次有效，出景区要办二次返山登记）。
3. **住宿今晚必须定**：距出发 8 天，台怀镇黄金周房源已经很紧。两晚都住台怀镇，不折腾。

## 住宿：两晚都住台怀镇，不换店

**结论：10/2、10/3 连住两晚，位置选杨柏峪 / 台怀镇中心区。**

理由很实际——你们不自驾，换店意味着拖着行李在景区里倒公交，纯浪费时间。台怀镇核心区寺庙密集、民宿最多、五台山汽车站就在附近，两晚扎在这儿最省事。

| | 安排 |
|---|---|
| **10/2 晚** | 台怀镇 · 杨柏峪一带民宿/酒店 |
| **10/3 晚** | 同一家，不退房不换店 |
| 房型 | 两间标间，或一套两居家庭房 |
| 国庆价预估 | 300–600 元/间/晚（平时 150–300，黄金周普遍上浮） |
| 两晚合计 | 约 1200–2400 元 |

**订房必问四件事**
1. 能不能免费接站/接集福寺停车场？（省一笔进镇的钱）
2. 房间有没有暖气或空调？10 月初山上夜里很冷，这条不能含糊
3. 早餐几点开？10/3 要赶早出门
4. 能不能代订大朝台车/包车？老板的渠道比你现场找靠谱

**备选区块**：杨柏峪订满了就退而求其次选明清街（吃饭方便）或大文殊寺附近（性价比高）。汽车站附近最便宜但离寺庙远，非必要不选。

## Day 1｜10/2（周五）太原南 10:00 到 → 台怀镇

### 太原南 → 五台山怎么走

**方案 A：太原南站直通巴士（推荐）**
- 2025 年 9 月开通的「太原—五台山」直通线路，**每日 7:00–17:00 整点发车，全天 20 班**，站点覆盖太原火车站、太原南站
- 车程约 3.5 小时
- **今天就在线上订 11:00 那班的 4 张票**，黄金周不预订就是赌运气

**方案 B：太原东客站**
- 票价 85 元/人，车程 3.5 小时，直达景区
- 缺点：先从太原南打车过去（30–40 分钟）；国庆排队可能 1 小时以上

**方案 C：四人包车**
- 约 240 公里，直接送到民宿门口，省掉后面的二级接驳
- 四人分摊未必比散票贵多少，省两小时折腾，值得问价

⚠️ **二级接驳**：巴士停靠点未必是台怀镇中心。到了之后可能还要转景区车或拼车进镇，预留 30 分钟。

- **午饭在太原南站解决**，上车前吃，车上 3.5 小时没得吃。

**今天是主力日，早起。**

| 18:30 | **晚饭 + 明清街逛街** | |

**黛螺顶怎么上（四人可以分头）**
- **走大智路**：1080 级台阶，40–60 分钟，最有仪式感。信徒三步一拜上去的就是这条
- **缆车**：单程约 50 元，往返 85–100 元（价格有浮动，现场看牌价）。简易缆车，恐高慎选
- **骑马**：马道崎岖，胆小别选
- **我的建议**：上行走台阶、下行坐缆车。体力不一样就分头走，山顶汇合——别为了整齐划一让走不动的人硬撑

**Day 2 吃饭**
- 午饭：**普化寺素斋饭**，38 元/位，自助或素食火锅，品类齐全，寺院氛围比餐馆强。
- 晚饭：明清街换一家。想图个稀奇可以试**素食德克士**（攻略说是全国唯一一家素食德克士，套餐约 50 元），当乐子体验。
- 随身：带水和干粮，黛螺顶上下没有像样的吃饭点。

## Day 3｜10/4（周日）二选一 + 返程

**先定一件事：几点的返程票。** 山路 + 黄金周出山堵车，**返程前留足 2 小时缓冲**，比平时多一小时。

### 方案 A：东台看日出（推荐，但有前提）

10 月初台顶已经很冷，东台夜里可能零下。这个方案只在你们有厚衣服、且愿意 4 点起床的前提下成立。

| 时间 | 安排 |
|---|---|
| 04:00 | 起床，包车去鸿门岩 |
| 05:00 | 鸿门岩 → 步行上东台（爬升约 300 米，1 小时） |
| 06:00–07:00 | **东台望海峰**看日出 + 云海。望海寺有斋饭，馒头咸菜粥，随喜约 10 元 |
| 08:00 | 下撤回鸿门岩，包车回镇上 |
| 10:00 | 回民宿取行李，退房 |
| 11:00 | 出发返程 |

**前提条件**：冲锋衣/厚外套 + 帽子手套是刚需，不是可选。10 月的台顶风大，七八月最热的月份台顶平均气温也才 9℃ 上下。

**不建议完整大朝台**：全程 60–72 公里、爬升 3000+ 米，两天起步，你们三天塞不进去，硬上只会变成赶路。

### 方案 B：慢游（省心，适合体力一般或起不来）

| 时间 | 安排 |
|---|---|
| 08:00 | 早饭，退房寄存行李 |
| 09:00–10:30 | **南山寺**：依山而建，石雕精美，台阶多但视野开阔 |
| 或 | **龙泉寺**：汉白玉牌坊号称雕了十年，108 级台阶 + 影壁 + 墓塔三绝，**不要门票** |
| 11:00 | **午饭** |
| 12:30 | 取行李，出发返程 |

**佛光寺不建议这次去**——唐代木构国宝，梁思成发现的那座，但在景区外、路程远，非自驾要包车单独占半天。值得专门跑一趟，不值得挤在返程日。

**Day 3 吃饭**
- 方案 A：东台望海寺斋饭（随喜约 10 元），下山后回镇上吃 **一盏明灯全素斋**（人均约 50 元，素鲍鱼、素排骨做得有肉味，沙棘汁解腻）
- 方案 B：**一盏明灯全素斋**当午饭，这是全山攻略出镜率最高的一家，别错过
- 返程路上带点干粮，黄金周堵车说不准

## 国庆档专属避坑

**关于人**
- 五爷庙、黛螺顶是全山人流最集中的两个点，**上午 10 点到下午 4 点是峰值**。Day 2 我把黛螺顶排在 7 点就是这个原因。
- 排队时看管好随身物品。
- 缆车队伍可能排 1 小时以上，走台阶反而更快——这是黄金周的反常识。

**关于钱**
- **高价香**：正规寺院门口免费提供清香，路边推销的高价香、祈福牌、开光饰品一律拒绝
- **假僧人**：主动搭讪算命、化缘消灾的基本都是假的，不扫码不转账
- **黑车**：包车认准官方运营，上车前问死「全程总价、到哪个具体位置、有没有额外费用」，避免中途加价
- **二次返山**：门票当日当次有效，出景区要办登记，24 小时内可再入。别随便出景区

**关于身体**
- 台怀镇海拔约 1700 米，台顶 2700–3061 米
- 心肺有问题的别硬上黛螺顶 1080 级台阶
- 10 月昼夜温差大，感冒药备上
